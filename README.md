## 📖 About The Project

**FreshMart** is a complete online grocery shopping platform that brings everyday essentials to your fingertips. From browsing categories and searching products to secure checkout with payments, managing your account, and paying utility bills — FreshMart delivers a seamless shopping experience.

## ✨ Features

| Feature | Description |
| :--- | :--- |
| 🏠 **Homepage** | Engaging landing page with featured products and promotions. |
| 🗂️ **Categories** | Browse products organized by category. |
| 🔍 **Search** | Quickly find products with a powerful search page. |
| 📦 **Product Pages** | Detailed product views with descriptions and pricing. |
| 🛒 **Shopping Cart** | Add, update, and manage items before checkout. |
| 💳 **Checkout & Payments** | Smooth checkout flow with integrated payment support. |
| 👤 **User Accounts** | Register, log in, and manage your profile. |
| 🎉 **Promotions** | Dedicated page for deals and special offers. |
| 🏢 **Brand Pages** | Featured brand collections (e.g., Keells products). |
| 🧾 **Utility Bills** | Pay utility bills directly through the platform. |
| 👥 **Community** | A community section for engagement. |
| 🔐 **Admin Panel** | Manage products, orders, and users from a dedicated dashboard. |
